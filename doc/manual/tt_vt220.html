VT220 Emulation in Kermit 95

Kermit 95 includes a fairly comprehensive VT220 emulation including features rarely implemented by other terminal emulators such as soft character sets (soft fonts / dynamically redefined character sets) and smooth-scroll.

VT220 is also Kermit 95s default emulation as it is present in most hosts terminfo database. You can also choose from one of two VT220 emulation options by selecting either vt220 or vt220pc from the drop-down list on the toolbar (K95G) or using the SET TERMINAL TYPE command.

Differences in K95s VT220 emulation

Any differences between Kermit 95s VT220 emulation and a real VT220 except for those noted below are likely a bug.

Functionality

The following functions are implemented differently in Kermit 95 vs a real VT220:

132 Column Mode
Instead of using a condensed font in 132-column mode, Kermit 95 changes the window size.
VT100 Confidence Tests (DECTST)
Kermit 95 does not implement this function
Interlaced Video Mode (DECINLM)
Kermit 95 does not implement this mode

If you want Kermit 95s VT220 emulation to use similar defaults to a real VT220, you can put the following in your k95custom.ini so that they run automatically when the VT220 or VT220PC terminal emulations are chosen. 

    def tt_vt220 {
        set terminal wrap off
        set terminal scroll-mode smooth
        set terminal color terminal lgray black
        set terminal cursor full on
        set terminal bytesize 7
        set terminal lock-key-definitions off  ; Enable DECUDK - a security risk
        set terminal sgr-colors off            ; A real VT220 doesn't support color
    }

    def tt_vt220pc {
        tt_vt220
    }

    ; K95s terminal emulator is initialised to VT220 before any startup scripts
    ; are run, so this is required to ensure tt_vt220 runs on startup.
    if equal \v(terminal) vt220 tt_vt220
